# Roblox Community Links

One icon. Tap it and your links open.

## Add your links
Open `main.py` and edit the `LINKS` list at the top.

## Put it on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload `index.html`, `style.css`, `main.py` and `README.md`.
3. Go to Settings > Pages. Under Branch, pick `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## Test on your computer
Opening `index.html` by double-click will not load `main.py`. Run this in the project folder instead:

    python -m http.server

Then open http://localhost:8000
